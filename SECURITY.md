# Security Policy

RepoContinuity is an early-stage local CLI foundation. Do not depend on it as a security boundary or proof of program correctness.

If you discover a vulnerability, **do not post credentials or exploit details in public issues**. Contact the repository maintainer through GitHub's private security advisory/reporting mechanism when available, or request a private reporting channel without sharing sensitive details publicly.

For scope and threat boundaries, see `docs/SECURITY_MODEL.md`.
