# Approved roadmap (as of 2026-11-10)

This plan is strictly phase-gated. CreativeCode Engine remains separate and unchanged.

- **Phase 1 — Foundation & Architecture (current):** collision/competitive audit, SQLite schema, safe CLI skeleton, tests, documentation, repo creation and read-back verification.
- **Phase 2 — Memory & Checkpoints (not started):** explicit decision/task CRUD, true Git checkpoint capture, evidence-backed status transition rules, SQLite migrations, JSON export design.
- **Phase 3 — AI Handoff & Skills (not started):** versioned Markdown/JSON packets, five reusable SKILL.md workflows, model-agnostic instructions and safe import validation.
- **Phase 4 — Public Release (not started):** end-to-end tests, package/release pipeline, quick start and public demo, security review, cross-platform matrix.
- **Phase 5 — Real User Validation (not started):** measure setup success, context recovery, incorrect completion claims, repeated use and user feedback.

## Phase 1 exit checks

- [x] Research competitor landscape and record risks.
- [x] Define architecture and boundary conditions.
- [x] Write CLI scaffolding and versioned SQLite schema.
- [x] Add local tests and CI configuration.
- [x] GitHub repository creation/push and independent remote verification.
- [ ] Final owner approval to begin Phase 2.

The boxes for local testing must be changed if tests fail. No phase transitions without approval.
